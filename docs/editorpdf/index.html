Textos editables

¿Y el DWG?

En el navegador se crea DXF; el DWG se saca en un clic desde AutoCAD

El DXF es un formato abierto que abren AutoCAD, BricsCAD, LibreCAD, QCAD y casi cualquier editor. Para tener un DWG, ábrelo en AutoCAD y usa Guardar como… DWG.

Escribir DWG directamente necesita una herramienta de Windows (ODA File Converter) que no puede ejecutarse en un navegador. Si lo prefieres, el programa para Windows crea DXF y DWG a la vez, y además reconoce letras dibujadas.

Preguntas frecuentes

¿Se suben mis planos a internet?

No. El PDF se lee y se convierte dentro de tu navegador; ningún dato sale de tu computadora. Puedes comprobarlo desconectando la red después de cargar la página.

¿Por qué un PDF escaneado no se convierte?

Un escaneo es una foto, no tiene líneas ni textos. Este conversor traduce las líneas, rellenos y textos que ya existen dentro del PDF, así que solo sirve con planos exportados desde un programa de dibujo.

El plano se ve igual, pero no puedo editar el texto

Pasa cuando el PDF se generó con las letras convertidas a dibujo. En el navegador esas letras quedan como dibujo (se ven igual). El programa para Windows tiene una opción experimental que intenta reconocerlas y crear texto editable.

La página tarda o el navegador se queda sin memoria

Prueba a convertir menos páginas cada vez, o sin la opción de unir todo en un archivo. El DXF de una página compleja puede pesar 10-15 MB.

¿Qué versión de AutoCAD necesito?

El DXF R2004 lo abre cualquier versión de AutoCAD desde 2004 y la mayoría de editores libres.
